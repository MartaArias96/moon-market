# 🌙 Moon Market

Moon Market es una tienda online aesthetic creada como proyecto de práctica frontend y desarrollo web.

El objetivo del proyecto es simular un eCommerce moderno con carrito interactivo, diseño responsive y funcionalidades dinámicas utilizando HTML, CSS, JavaScript y PHP.

---

# ✨ Funcionalidades

- Diseño responsive 📱
- Carrito lateral interactivo 🛒
- Añadir y eliminar productos
- Persistencia de carrito con localStorage
- Animaciones y efectos visuales
- Interfaz aesthetic dark mode 🌙

---

# 💻 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- LocalStorage

# 🚀 Cómo ejecutar el proyecto

1. Clonar repositorio:

```bash
git clone https://github.com/MartaArias96/moon-market.git
```

2. Mover proyecto a:

```txt
C:/laragon/www/
```

3. Iniciar Laragon

4. Abrir en navegador:

```txt
http://moon-market.test
```
